## Text detection selection

[Binoculars methodology](https://arxiv.org/abs/2401.12070) studies comparison of model perplexity and cross-perplexity; two large language models are a poor normal-phone fit for this launch. [Binoculars code](https://github.com/ahans30/Binoculars) and [HC3](https://github.com/Hello-SimpleAI/chatgpt-comparison-detection) were reviewed for methodology only. Repository/model/data licensing was not conclusively verified for commercial reuse here, so none of their code, weights or corpus is bundled.

[RoBERTa GPT-2 detector model card](https://huggingface.co/openai-community/roberta-base-openai-detector) describes a GPT-2-era classifier. Its training scope does not justify claiming current ChatGPT/Gemini authorship detection. It was not installed. A runtime's permissive license does not establish a weight/dataset license or detector calibration.

TRACEFIELD currently uses original local style-feature code with low confidence, not a trained classifier. The benchmark harness accepts provenance-labelled JSONL corpora and reports category outcomes. Developer smoke cases are not an accuracy benchmark. Genuine human/ChatGPT/Gemini, edited/paraphrased, non-native, short/long samples and a held-out evaluation are still required before selecting any model or showing calibrated likelihood. The UI states these limits.

## Inherited runtime / UI / build stack

React, TanStack, Vite, Nitro, Better Auth, pg, Kysely and PGlite remain npm dependencies. Better Auth handles credential hashing/session persistence; pg serves the existing Neon schema. PGlite is a disposable development/test fallback only. Tailwind, Lucide and the inherited Radix button primitive preserve the original styling; unused UI components are tree-shaken. Alternatives (new framework/auth vendor/database) were rejected to avoid migration risk. Framework and Nitro beta versions require ongoing integration checks; these packages are not forensic evidence engines.

Security audit after compatible brace-expansion updates: **0 npm-reported vulnerabilities** on 2026-10-02. This is a registry advisory check, not proof of complete security. Package-lock pins reviewed resolved versions. Browser raw-file limits and separate workers constrain parser cost; no third-party AI endpoint receives local file/text bytes. Google Fonts remains a stylesheet/font request and receives ordinary request metadata; it can be self-hosted later.
